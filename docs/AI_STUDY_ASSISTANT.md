# AI 研学问答与普通话试听说明

本文记录王同学负责的 AI 研学问答、知识来源和普通话讲解试听的实现边界。当前内容用于比赛演示与教学，不代表景区正式发布资料。

## 功能范围

- 问答页支持自由输入（最多 200 字）、推荐问题、重复提交防护、网络失败重试和来源展示。
- Express API 与 CloudBase 云函数都提供 `GET /assistant/suggestions` 和 `POST /assistant/chat`，并使用相同的来源结构和兜底文案。
- 回答只来自审核 FAQ、项目登记的景点/路线/服务资料和受控规则，不调用开放式生成模型。
- 未命中可靠资料，或票务、开放、交通、拍摄、无障碍等资料未配置时，回答必须以“未找到可靠资料”开头，不附伪造来源。
- 景点页支持普通话试听的播放/暂停、进度、前后跳转、倍速、云端到本地降级；最终播放失败时保留文字稿并显示持续错误提示。

## 测试矩阵

| 场景 | 预期结果 | 自动化覆盖 |
|---|---|---|
| 正常文化问题 | 返回审核稿、结构化来源、审核状态 | API 测试 |
| 推荐问题 | 返回带分类的受控问题和 200 字边界 | API 测试 + 集中验收 |
| 无答案或政策未配置 | 以“未找到可靠资料”开头，来源为空 | API 测试 |
| 空问题/超长问题 | 返回明确的 400 错误码 | API 测试 |
| 问答断网 | 页面保留原问题并提供“重新尝试” | 集中静态验收；开发者工具断网需人工复核 |
| 普通话试听 | 15 个 URL、类型和实体 WAV 一一对应 | 数据库批处理测试 + 集中验收 |
| 云端音频失败 | 自动切换本地 API 音频 | 集中静态验收；开发者工具需人工复核 |
| 音频全部失败 | 页面持续显示失败原因，文字稿仍可阅读 | 集中静态验收；开发者工具需人工复核 |

## 人工复核步骤

1. 在微信开发者工具导入 `frontend/`，分别验证模拟器和真机的自由提问、推荐问题、来源链接复制和失败重试。
2. 临时断开网络提交问题，确认页面显示可重试错误；恢复网络后点击“重新尝试”。
3. 打开任一景点，验证播放、暂停、进度、前后 15 秒和倍速；阻断云文件后确认切换本地音频，再阻断本地 API 确认文字稿和持续错误提示仍可见。
4. 对 15 条讲解逐条校对人名、地名、多音字和背景噪声；完成景区/专家审核后才能把审核状态改为正式发布。

自动化命令在 `backend/` 目录执行：

```powershell
npm.cmd test
npm.cmd run acceptance:check
```
